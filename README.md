# DIS08 Data Modeling Project  
## Rental Prices in North Rhine-Westphalia (NRW)

This project is part of the course **DIS08 – Data Modeling**.  
It follows the OSEMN framework (Obtain, Scrub, Explore, Model, Interpret).

The goal is to analyze rental apartment offers in North Rhine-Westphalia (NRW)
and to investigate how rental prices vary across cities and housing characteristics.

---

## Dataset

**Source:**  
Apartment Rental Offers in Germany (Kaggle)

**Description:**  
The dataset contains apartment rental listings from Germany, including information
about rent, living space, number of rooms, location, and selected housing features.

The analysis focuses exclusively on **North Rhine-Westphalia (NRW)**.

Raw data is stored locally and excluded from version control.

---

## Research Questions

1. How do rental prices per square meter differ between cities in NRW?
2. Are smaller apartments more expensive per square meter than larger apartments?
3. Do housing characteristics (e.g. balcony, kitchen, year of construction)
   have a measurable influence on rental prices?
4. Can rental offers in NRW be grouped into distinct patterns using data analysis methods?
