# DIS08 Project Plan – Rental Prices in NRW

This document outlines the project roadmap according to the OSEMN framework.

---

## Obtain
- Load the raw dataset from Kaggle
- Inspect structure, columns, and basic statistics
- Filter data for North Rhine-Westphalia (NRW)

## Scrub
- Remove invalid or missing values
- Select relevant variables (rent, living space, rooms, location)
- Create derived variables (e.g. price per square meter)
- Handle outliers

## Explore
- Descriptive statistics (mean, median, quartiles)
- Visualize rental price distributions
- Compare rental prices across cities
- Explore relationships between housing size and price

## Model
- Group comparisons (e.g. small vs. large apartments)
- Hypothesis testing using non-parametric tests
- Optional: clustering or pattern detection

## Interpret
- Summarize findings in context of housing affordability
- Discuss limitations of the dataset
- Prepare results for presentation and poster
